own **source**: edit them directly. They began as generated ports of `vendor/nba_betting_repo`
(mostgood1/NBA-Betting) and, for the shared engine and orchestrator, `vendor/wnba_betting_repo`
(mostgood1/WNBA-Betting), **frozen at Syndicate commit `27ef92f8` (2026-10-08)**, the last commit to touch the NBA

## What the copies carry (keep it when editing)

- `wnba/live_tick`: the one deliberate departure from the vendored text, `current_last_updates` on the nested
  `_update_registry_bucket` (marked `# FIX wnba-registry-current-last-updates`; without it the WNBA live-props registry was
  never written). `tests/test_basketball_live_tick_fixes.py` rebuilds the unfixed text from this file and pins both
  behaviours. `nba/live_tick` is the vendored text.
  The data root is `NBA_BETTING_DATA_ROOT`, else `data/nba_source/data`, never the vendored repo.
- The #626(e) gate `_tick_prop_klass_line_gate` (never BET on a model line) is in `nba/live_tick/tick.py` and
  `wnba/live_tick/tick.py`; `tests/test_basketball_live_tick_reachability.py` and
  `tests/test_live_lens_tick_klass_gate.py` pin it on these files.
- `nba/source_cli`: models are byte-identical copies in `source_cli/repo/models`; `predict-date` carries upstream's
  `_build_slate_from_game_odds` fallback.
- `wnba/source_cli/scrapers/injuries.py`: the WNBA `fetch-injuries` reads ESPN's WNBA page only (2026-10-22, lane
  `wnba-injury-nba-report`). The vendored text preferred the NBA's official report PDF and Rotowire's `/basketball/`
  page, both the NBA's, and wrote NBA rows as the WNBA day's snapshot; both scrapers are deleted from this copy.
  `tests/test_wnba_injury_nba_report.py` pins it. Do not port the NBA copy's official scraper back.
