Earlier in this log I wrote that the collector "fired and produced nothing" and

Modern Standby (S0 low-power idle) keeps the network alive — which is why the
scheduler fired and the model produced a tool call — while the Desktop Activity
Moderator suspends user-mode processes. So the session could *decide* to run the
script and could not *run* it. The board rolled past midnight CT in between, and
the 23:25 CT cron exists precisely to beat that roll.

### The collector is now WORKER-SIDE — `74f026a9`, pushed, NOT deployed

The cause above is fixed at the design level rather than patched: retention no
longer depends on a laptop being awake.

**What changed.** `syndicate/features/shared/live_gameline_accuracy.py` (NEW)
retains the score; `book_grid_artifact.py` calls it immediately after

`tests/test_live_gameline_accuracy.py` (22 tests) covers it.

**Three failure modes removed, not one.**

| failure | old | now |
|---|---|---|
| task disabled | six nights lost, silently | no task to disable |
| machine asleep | 9h13m stall, empty capture | worker is always awake |
| wall-clock DEADLINE | one attempt vs the midnight roll | every build; fullest wins |

The third was latent and is the one worth naming: a 23:25 CT cron gets a single
attempt against the slate roll, so ANY single failure is total. The worker
rebuilds every few minutes, so retention is continuous and the most complete
build of the night wins on its own.

**Append only when `games_with_outcome` IMPROVES**, so the build rate does not
multiply the file. Exercised against the REAL 08-27 production payload: record
(4) → skip identical rebuild → record improvement (15); pooling then picks 15.
~1.4KB/row, so a year is ~500KB against a 12MB sweep ceiling.

**The allowlist entry is NOT decorative, and that was checked.** `write_json_file`
routes everything outside `migration_runs/` to keyvalue and returns before
touching disk, which would make a `HOT_ARTIFACT_PATTERNS` entry inert — a 403
turned into an empty result (`learnings.md` 2026-08-27 FORBIDDEN). This writes
with a direct `path.open("a")` under `data/`. Proven against the sweep's own
`root.glob`, plus `_artifact_date(path) is None` (a parsed date would classify
it `stale_slate` forever while every pattern test still passed) and
`_publish_skip_reason(...) is None`.

**Reachability before correctness.** `test_board_build_reaches_the_recorder`
spies the seam rather than the output — a fixture can produce a plausible file
down a path the builder never took. The kill switch is asserted to be consulted
(`off != on`), and absent asserted to mean ENABLED.
