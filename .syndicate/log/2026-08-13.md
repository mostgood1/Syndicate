## VERIFIED, with evidence

- **`#417` — the board served a 4h12m-stale payload.** `written_at` stuck at
  `10:56:10Z`; rebuilt `15:08:04Z` only after an unrelated deploy restarted the
  worker at `14:56:02Z`.
- **Cause: `MEMORY_GUARD_ABORT stage=pre_source_state_fingerprint`**, 300
  consecutive cycles ~65s apart, `09:29:27Z -> 14:54:44Z`, zero gaps, one stage.
  Guard is `_MIN_SAFE_MEMORY_HEADROOM_BYTES = 1900MB`
  (`pipeline/intelligence_state.py:3189`, call site `:5266`). It aborts *before*
  the fingerprint, so the whole cycle dies: no shortlist, no artifact write.
- **NOT a leak — measured, not assumed.** `anon` across all 300 samples: first
  1659.0, last 1677.9, min 1635.0, max 1951.2. **Drift +18.9 MB over 5.4h.**
- **Mechanism: a page-cache reclassification.** At ~11:02 the kernel moved
  ~243 MB from `inactive_file` to `active_file`. Total file cache *shrank*
  (1289 -> 1015 MB) and `current_mb` *fell* (3120 -> 2705), yet effective
  headroom dropped 1877 -> 1643 and never recovered, because
  `memory_headroom_snapshot` credits only `inactive_file + slab_reclaimable`.
- **`#401` is not a defect.** Last run `2026-08-12 23:38:06Z`, checked
  `15:15:15Z` -> 15.62h elapsed against an 86400s interval
  (`_INTERVAL_DEFAULT_SECONDS`; `SYNDICATE_DISK_MAINTENANCE_INTERVAL_SECONDS`
  read as unset on **both** workers via the env-vars API). Short by 8.38h.
- **The internal-hostname cutover is live**, observed directly in worker logs
  at `14:54:11Z`: `PUBLISH_OK ... url=http://syndicate-an21:10000/api/ops/...`
  on every publish line, plus `PUBLISH_BUDGET uploads=915 used_mb=302.4
  ceiling_mb=20480.0`.
