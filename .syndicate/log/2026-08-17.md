Scheduled task `mlb-tie-baseline-pregame`, fired 2026-08-17 ~09:54 CDT. It

**Result: the slate. MLB is now BASELINED, both widths.**

### Precondition — PASSED

`cardHeightByState` carried exactly one state on every run and both widths:

    Preview: n=11, min 853, max 1253   (desktop)
    Preview: n=11, min 3087, max 4416  (mobile)

All 11 cards pre-game, no `Live`, no `Final`, no delay state. First pitch had not

### Stability — three runs, and they were BIT-IDENTICAL

Against `https://syndicate-an21.onrender.com`, `worstGroupPx` / `spreadPct`:

| run | desktop | mobile |
|---|---|---|
| 1 | 86px / 7.1% | 43px / 1.1% |
| 2 | 86px / 7.1% | 43px / 1.1% |
| 3 | 86px / 7.1% | 43px / 1.1% |

Not "within 1.2x" — **identical**, and identical down to every per-group figure
(desktop `49:86, 41:61, 45:28, 53:5`; mobile `45:43, 49:32, 53:30, 41:3`;
`tiedGroups=4, cardsTied=10` on both). Two further production runs during Step 3
(the baseline write and the comparison re-run) read 86/43 again — **five
consecutive identical readings**. The decision rule fixed in advance (~1.2x)
passes with room to spare, on both widths, so both were armed.

The 2026-08-16 readings were sampling a board that was still enriching. The
metric was never the problem.

**First pitch will not read as a layout regression.** The tie spread is
per-state, so once `Preview` becomes `Live` the two sides are different
quantities: `compare()` prints `NOT COMPARABLE -- state moved` and leaves `ok`
alone. Verified by reading the branch and by a test
(`test_mlb_first_pitch_is_not_comparable_rather_than_drift`). Drift can only be
raised against a baseline captured in the SAME state — so re-baseline pre-game.

### Four existing tests had to be repointed, and that is worth knowing

`_report()` defaults to `sport="mlb"`, so four tests were silently exercising the
**watch-only** branch through the default sport. Arming mlb moved them to the
judged branch and they failed. Fixed by intent, not by chasing strings:

- the two tests genuinely ABOUT the watch branch now pass `sport="soccer"` —
  soccer holds that branch open now that mlb has left it;
- the two about `_cmp_value`'s worst-group semantics stayed on mlb, where `ok` is
  now load-bearing: were the comparator to read `largestGroupPx`, it would no
  longer merely misprint, it would FAIL the run. Those tests got stronger.

**The general trap:** a test that takes a branch via a DEFAULT argument does not
say so, and opting a sport in silently rewrites which branch it tests.
