## lane `nfl-fantasy-artifact-root` — follow-up: the sweep, done — session 4b1b66a3

The lane closed 2026-09-05 with one caveat recorded as NOT verified: *"whether
any OTHER test repoints an artifact root without disabling the fallback. The
same shape would be invisible the same way."* Swept 2026-09-06. **It is the
only instance.**

### Method
An AST pass over all 989 `tests/test_*.py`, per TEST FUNCTION rather than per
file, looking for the conjunction that makes the defect: repoints
`SYNDICATE_*_{SOURCE,DATA,ARTIFACT}_ROOT`, asserts ABSENCE, does not set
`SYNDICATE_REQUIRE_HOSTED_STORAGE`.

Repoint-then-write-then-assert-PRESENCE is deliberately not flagged: the mirror
can only ADD candidates, so a file that is present is still found. Only the
absence assertions are unsound.

### THE INSTRUMENT WAS VALIDATED BEFORE ITS NULL RESULT WAS BELIEVED
Run against the pre-fix file (`63ab36a0^`), the sweep flagged **3 of 3**
known-bad tests. Without that check a null result would have meant nothing.

### Believed but NOT verified
* The sweep is STATIC and literal. A repoint performed inside a fixture or
  helper, or an absence written as `len(x) == 0` / `assert not payload`, would
  not match. This lane's own fixed test proves the blind spot is real: moving
  the guard into a helper made the regex stop seeing it.
* It cannot tell whether the artifact is actually present in a given
  developer's `data/` mirror, which is what decides real-world exposure.
